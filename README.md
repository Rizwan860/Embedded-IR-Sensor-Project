# Embedded IR Sensor Project

## Overview
This project demonstrates object detection using an IR sensor with ESP32.

## Features
- Object detection
- LED indication
- Serial Monitor output
- Simple embedded implementation

## Components Used
- ESP(32)
- IR Sensor
- LED
- Jumper Wires

## Working
When an object comes near the IR sensor:
- Sensor detects reflection
- LED turns ON
- Message displayed on Serial Monitor

## Applications
- Obstacle avoiding robot
- Automation systems
- Industrial object counting
- Embedded projects
